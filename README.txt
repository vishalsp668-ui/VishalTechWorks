VishalTechWorks Portfolio

Personalized for an aspiring AI/ML Engineer interested in AI/ML and Web Development.
Education details are left open because the exact qualification was not provided.

RUN LOCALLY
1. Extract this ZIP.
2. Open the VishalTechWorks folder in VS Code.
3. Open index.html and click Go Live (Live Server).

PERSONALIZE BEFORE PUBLISHING
1. In script.js, replace your-email@example.com with your actual email address.
2. Add your exact education details in index.html.
3. Replace sample projects with projects you have actually built.
4. Add GitHub and LinkedIn URLs when your profiles are ready.
5. To show a CV, put a PDF named Vishal-CV.pdf in this folder.

No background photo is used; no image is required.
The contact form opens an email draft using mailto; it does not send to a server.
